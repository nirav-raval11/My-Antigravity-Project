## 🛡️ Cyber Security & Hardening (OWASP Top 10)
This web application is secured against real-world attack vectors:
- **XSS & HTML Injection Sanitization:** Active encoding of input fields via `SecurityDefense.sanitize()`.
- **Content Security Policy (CSP):** Strict origin white-listing on scripts, fonts, and assets.
- **Anti-Clickjacking:** `X-Frame-Options: SAMEORIGIN` enabled.
- **MIME-Sniffing Defense:** `X-Content-Type-Options: nosniff`.
- **Anti-Bot Honeypot:** Invisible trap fields intercepting malicious automated spiders.
- **Career Resume Security:** Strict 5MB size ceiling, document whitelist (`.pdf`, `.doc`, `.docx`), and double-extension prevention.
- **Rate Limiting:** Sliding-window throttling preventing inquiry spam flooding.

## 🚀 Instant Deployment to Vercel

### Option 1: One-Click Import via GitHub (Recommended)
1. Push this repository to your **GitHub** account.
2. Open **[vercel.com](https://vercel.com)** and sign in with GitHub.
3. Click **"Add New..."** -> **"Project"**.
4. Import your `surya-construction` repository.
5. Keep default settings (Framework Preset: **Other**) and click **"Deploy"**.
6. Your site will be live instantly with a free SSL certificate: `https://surya-construction.vercel.app`!

### Option 2: Drag & Drop via Vercel Dashboard (Zero Git Needed)
1. Go to **[vercel.com/new](https://vercel.com/new)**.
2. Drag and drop this project folder directly onto the Vercel deploy area.
3. Get a live URL in 30 seconds!
